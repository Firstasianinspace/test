# Проверки безопасности

Автоматические тесты: `supabase/tests/security.test.ts` (`pnpm test:db`, против локального Supabase). Они ходят в PostgREST напрямую с anon-ключом и сессиями реальных пользователей — то есть в обход интерфейса.

| #   | Проверка                                                                                                  | Ожидаемый результат              |
| --- | --------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 1   | Исполнитель читает чужие задачи / историю / объекты / профили                                             | пусто                            |
| 2   | Запрещённые переходы (new→accepted, same, чужой исполнитель, постановщик за исполнителя, без исполнителя) | ошибки CRT01/CRF01/CRN01/CRA01   |
| 2a  | Прямой UPDATE статуса                                                                                     | 42501 permission denied          |
| 3   | INSERT/UPDATE/DELETE по истории                                                                           | 42501                            |
| 4   | Анонимный доступ и регистрация                                                                            | пусто / ошибка                   |
| 5   | Исполнитель правит поля, создаёт, удаляет, меняет роль                                                    | 0 строк / ошибка                 |
| 6   | Доработка без комментария (пустой, из пробелов)                                                           | CRC01; полный цикл пишет историю |
| 7   | Не-исполнитель как исполнитель, подделка author/status, удаление объекта с задачами                       | CRV01 / 42501 / 23503            |

## Результаты последнего прогона

Прогон на локальном Supabase: `pnpm test:db` — **32 из 32 тестов пройдено**; `pnpm e2e` — **5 из 5** (в том числе полный цикл через интерфейс с доработкой и комментарием, 7 записей истории, недоступность чужой задачи по прямой ссылке) (включая прямую PATCH-атаку на статус из контекста браузера под сессией исполнителя: отклонена). После `pnpm build` строка `service_role` не встречается ни в `src`, ни в `dist`.

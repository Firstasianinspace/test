# Спецификация — мини-CRM «Объекты и задачи»

Источник: `ASSIGNMENT.md`. Кратко:

**Роли.** Постановщик: CRUD объектов и задач, назначает исполнителя, принимает/возвращает на доработку, видит всё. Исполнитель: видит только свои задачи и объекты, где у него есть задачи; берёт в работу и отправляет на проверку.

**Объект:** название, адрес; в карточке — список задач со статусами.
**Задача:** название, описание, объект, исполнитель, статус, автор, дата создания.

| Из           | В            | Кто                     | Условие                |
| ------------ | ------------ | ----------------------- | ---------------------- |
| —            | Новая        | постановщик             | при создании           |
| Новая        | В работе     | назначенный исполнитель | —                      |
| В работе     | На проверке  | назначенный исполнитель | —                      |
| На проверке  | Принята      | постановщик             | —                      |
| На проверке  | На доработке | постановщик             | комментарий обязателен |
| На доработке | В работе     | назначенный исполнитель | —                      |

Остальные переходы запрещены. Каждая смена статуса пишется в историю (кто, когда, из→в, комментарий), история видна обеим ролям.

**Экраны:** вход (email+пароль), список объектов, карточка объекта, карточка задачи (данные, действия, история), «Мои задачи».

**Безопасность:** RLS; исполнитель не читает/не меняет чужое; переходы проверяются в БД; история неизменяема через API; регистрация отключена; секреты не в репозитории.
